Show only the application settings and tabs that apply to the client's application type. Machine-to-Machine clients no longer show the Connections, Organizations and Refresh Tokens tabs, the login-screen options or the Login button. Client Grants shows for Machine-to-Machine clients and for any confidential client with the Client Credentials grant. SSO is hidden for Native and Machine-to-Machine clients unless a SAML addon is already configured.
