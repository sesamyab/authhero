Admin UI for the `custom-email-provider` and `custom-phone-provider` triggers (issue #1797):
- Both triggers appear on the Triggers page with starter code.
- A binding can be limited to chosen message types, and the Triggers page shows what each binding delivers.
- The email provider page has a "Custom (action)" provider.
- The email provider and MFA SMS pages show which action delivers which messages, with a link to the trigger.
