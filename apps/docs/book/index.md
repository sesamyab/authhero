# The AuthHero Book

Most documentation answers the question *how do I configure this?* This book answers the one that comes before it: *what is this, and why does it work that way?*

It starts with what a login actually is and ends with running AuthHero in production. On the way it covers tokens, sessions, single sign-on, multi-factor authentication, permissions, organizations, extensibility and multi-tenancy. Each chapter explains the idea first, in plain terms, and then shows how AuthHero handles it.

## Who it is for

- **Developers adding login to a product** who want to understand what the libraries are doing on their behalf.
- **Teams evaluating AuthHero** who want the whole picture before reading reference pages.
- **Anyone who has nodded along** when someone said "the access token's audience is wrong" and would like to nod sincerely next time.

You need to know roughly what an HTTP request and a cookie are. Nothing else is assumed.

## How to read it

Front to back. The chapters are short, about five minutes each, and each one builds on the ones before. A small fictional company called Larder, which makes kitchen software for restaurants, appears throughout and grows a new requirement in most chapters.

Every chapter ends with links to the reference pages for the features it covered. Read the book for the shape of things, then use the reference when you sit down to build.
